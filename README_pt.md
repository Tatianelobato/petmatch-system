\# 📋 Requisitos do Sistema \& Histórias de Usuário



\## 1. Requisitos Funcionais (RF)

\*   \*\*RF001:\*\* O sistema deve permitir que as ONGs cadastrem animais com foto, idade, porte e temperamento.

\*   \*\*RF002:\*\* O sistema deve permitir que os adotantes pesquisem e filtrem animais por espécie e porte.

\*   \*\*RF003:\*\* O sistema deve validar a elegibilidade do adotante automaticamente com base nas regras do abrigo.



\## 2. Requisitos Não-Funcionais (RNF)

\*   \*\*RNF001 (Usabilidade):\*\* A interface do formulário de adoção deve ser simples e limpa para todos os usuários.

\*   \*\*RNF002 (Conformidade/Lei):\*\* O sistema deve estar em conformidade com o regulamento de proteção de dados (GDPR/LGPD) em relação aos dados pessoais dos usuários.



\## 👤 3. Histórias de Usuário (User Stories)

\*   \*\*Como\*\* representante de uma ONG, \*\*eu quero\*\* cadastrar animais resgatados \*\*para que\*\* eles ganhem visibilidade na plataforma.

\*   \*\*Como\*\* um potencial adotante, \*\*eu quero\*\* filtrar animais por temperamento \*\*para que\*\* eu possa encontrar um animal adequado para o meu estilo de vida em apartamento.
