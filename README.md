\# 🐾 PetMatch - Pet Adoption Management System



\## 📌 Project Overview

\*\*PetMatch\*\* is a software project designed to connect animal shelters (NGOs) with potential pet adopters. The system aims to streamline the adoption process, reduce shelter overcrowding, and ensure pets are matched with responsible owners based on compatibility rules.



This repository is being developed \*\*incrementally\*\* as I progress through my Software Engineering Bachelor's degree. 



Current Phase: \*\*1st Semester (Fundamentals \& Requirements)\*\*

\## 🛠️ Tools \& Methodologies (1st Semester)

\*   \*\*Agile Methodology (Scrum/Kanban):\*\* Used for task organization and sprint planning.

\*   \*\*Requirements Engineering:\*\* Used to map features and constraints based on real-world needs.

\*   \*\*Logic \& Decision Trees:\*\* Used to define the business rules for adoption approval.
