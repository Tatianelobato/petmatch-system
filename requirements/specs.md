\# 📋 System Requirements \& User Stories



\## 1. Functional Requirements (FR)

\*   \*\*FR001:\*\* The system must allow NGOs to register pets with photo, age, size, and temperament.

\*   \*\*FR002:\*\* The system must allow adopters to search and filter pets by species and size.

\*   \*\*FR003:\*\* The system must validate the adopter's eligibility automatically based on shelter rules.



\## 2. Non-Functional Requirements (NFR)

\*   \*\*NFR001 (Usability):\*\* The adoption form interface must be simple and clean for all users.

\*   \*\*NFR002 (Compliance):\*\* The system must comply with GDPR (General Data Protection Regulation) regarding users' personal data.



\## 👤 3. User Stories

\*   \*\*As an\*\* NGO representative, \*\*I want to\*\* register rescued animals \*\*so that\*\* they gain visibility on the platform.

\*   \*\*As a\*\* potential adopter, \*\*I want to\*\* filter pets by temperament \*\*so that\*\* I can find an animal suitable for my apartment lifestyle.
